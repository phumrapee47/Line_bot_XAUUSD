📈 SIGNAL GENERATION FLOW

┌──────────────────────────────────────────────────────────────┐
│ Every 60 minutes (or manual trigger via POST /api/check-signal)
└──────────────┬───────────────────────────────────────────────┘
               │
               ↓
┌──────────────────────────────────────────────────────────────┐
│ 1. TECHNICAL ANALYSIS                                        │
│    • Fetch 90 days × 1 hour candles (GC=F from yfinance)    │
│    • Calculate: return, RSI-7/14/21, EMA-10/20/50/200       │
│    • Calculate: MACD, ATR, Bollinger Bands                  │
│    • Load XGBoost model from pkl file                       │
│    • Predict: Probability of price UP (0.0 to 1.0)         │
│    └─> Output: tech_score (60% weight)                      │
└──────────────┬───────────────────────────────────────────────┘
               │
               ↓
┌──────────────────────────────────────────────────────────────┐
│ 2. NEWS SENTIMENT ANALYSIS                                   │
│    • Fetch gold-related news from FXStreet RSS              │
│    • Filter: Only titles/summaries with gold/XAU keywords   │
│    • Analyze each article for bullish/bearish words         │
│    • Calculate sentiment: (bullish_count / total_words)    │
│    └─> Output: news_score (40% weight)                      │
└──────────────┬───────────────────────────────────────────────┘
               │
               ↓
┌──────────────────────────────────────────────────────────────┐
│ 3. COMBINE SCORES                                            │
│    final_score = (tech_score × 0.6) + (news_score × 0.4)   │
│    confidence = final_score × 100%                          │
└──────────────┬───────────────────────────────────────────────┘
               │
               ↓
┌──────────────────────────────────────────────────────────────┐
│ 4. DETERMINE SIGNAL                                          │
│                                                              │
│    if final_score > 0.60:                                   │
│        signal = "🟢 BUY"                                    │
│    elif final_score < 0.40:                                 │
│        signal = "🔴 SELL"                                   │
│    else:                                                     │
│        signal = "⚪ HOLD"  (no LINE notification)           │
└──────────────┬───────────────────────────────────────────────┘
               │
               ↓
┌──────────────────────────────────────────────────────────────┐
│ 5. CALCULATE RISK MANAGEMENT                                 │
│    • Get current price and ATR (Average True Range)         │
│    • If BULLISH prediction:                                 │
│        - TP (Take Profit) = Price + (3.0 × ATR)           │
│        - SL (Stop Loss) = Price - (1.5 × ATR)             │
│    • If BEARISH prediction:                                 │
│        - TP = Price - (3.0 × ATR)                          │
│        - SL = Price + (1.5 × ATR)                          │
└──────────────┬───────────────────────────────────────────────┘
               │
               ↓
┌──────────────────────────────────────────────────────────────┐
│ 6. SEND NOTIFICATION (if signal changed or is BUY/SELL)    │
│    • LINE message includes:                                  │
│      - Signal emoji & type                                  │
│      - Confidence percentage                                │
│      - Technical score                                      │
│      - News score                                           │
│      - Current price                                        │
│      - Take Profit level                                    │
│      - Stop Loss level                                      │
│      - Timestamp                                            │
│    • Message via LINE Notify API                            │
└──────────────┬───────────────────────────────────────────────┘
               │
               ↓
         📱 LINE App
      Notification Received

🚀 HOW TO START

1️⃣  Get LINE Token
    └─ Visit: https://notify-bot.line.me/
    └─ Login → Generate Token → Copy

2️⃣  Configure .env
    └─ Open .env file
    └─ Paste: LINE_NOTIFY_TOKEN=your_token_here

3️⃣  Run Setup
    └─ Windows: Double-click setup.bat
    └─ macOS/Linux: bash setup.sh

4️⃣  Start Bot
    └─ cd backend
    └─ npm start

5️⃣  Watch for Signals
    └─ Check backend/logs/combined.log
    └─ Wait for LINE notification with signal
    └─ Or manually trigger: curl -X POST http://localhost:3000/api/check-signal
