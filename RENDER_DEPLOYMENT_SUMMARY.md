## 📁 Key Files for Render

### **render.yaml** (Root Directory)
```yaml
services:
  - type: pserv
    name: trading-bot-db                    ← PostgreSQL
    
  - type: web
    name: xauusd-trading-bot-frontend       ← Frontend
    buildCommand: cd frontend && npm install
    startCommand: cd frontend && npm run serve
    
  - type: web
    name: xauusd-trading-bot-backend        ← Backend
    buildCommand: cd backend && npm install && node seeds/seedTradingPairs.js
    startCommand: cd backend && npm start
    depends_on:
      - trading-bot-db                      ← Depends on DB
```

### **frontend/package.json**
```json
{
  "scripts": {
    "serve": "http-server . -p 3001 -g"    ← ทำให้ render.yaml ใช้ได้
  }
}
```

### **backend/src/server.js**
```javascript
// CORS middleware for frontend access
app.use((req, res, next) => {
  res.header('Access-Control-Allow-Origin', 
    process.env.FRONTEND_URL || '*');
  // ...
});
```

### **Common Issues**

| Error | Cause | Fix |
|-------|-------|-----|
| "Build failed" | Syntax error in code | Check git logs |
| "Cannot connect" | Database not ready | Wait 30 sec |
| "Port in use" | Service conflict | Render handles this |
